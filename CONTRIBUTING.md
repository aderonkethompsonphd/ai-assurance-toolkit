# Contributing

Contributions are welcome via issues and pull requests.

**Most useful right now**
- Practitioner review of the `frontier/` module (is it usable? what is missing?)
- Additional sector questionnaires
- Translations
- Automation scripts (for example scoring from a filled questionnaire)
- Corrections to framework references

**Guidelines**
- Cite the exact clause or article for any framework mapping.
- Keep questions answerable with evidence, not opinion.
- Mark anything uncertain as a draft.
- By contributing you agree your work is released under CC BY 4.0.
